# Quick Plan: enlarge mascot icon past tile edge and clip so gradient tile is fully covered

## Problem

Follow-up to 261115-nwe: the mascot now renders at the full 40×40 tile, but
`public/mascot_icon.png` has its rounded corners baked in as transparent
pixels, so the gradient tile (`rounded-[16px]` span) still peeks through at
the corners.

## Tasks

### 1. Scale the image past the tile edge and clip it

- **files:** `apps/web/src/components/NavBar.jsx`
- **action:**
  - Add `overflow-hidden` to the logo span so anything past its
    `rounded-[16px]` edge is clipped.
  - Add `scale-125` to the img (40px rendered at 50px, centered): the ~5px
    overshoot pushes the PNG's transparent corner lens fully outside the
    clip, so the gradient is covered everywhere while the tile keeps its
    16px-rounded shape (corners now show mascot artwork clipped to the
    tile radius).
- **verify:** `npm run build` in `apps/web` green; visually no gradient
  ring/circle visible behind the mascot at any corner.
- **done:** Gradient tile fully covered by the enlarged, clipped mascot.

## Constraints

- NavBar.jsx only; the span (shadow, rounding) stays — only overflow +
  scale classes change.
