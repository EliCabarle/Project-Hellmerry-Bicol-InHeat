# Quick Plan: fix stray ErrorBoundary closing tag breaking vite build in app.jsx

## Problem

Vite dev/build fails with a Babel parse error in `apps/web/src/app.jsx`:

```
Adjacent JSX elements must be wrapped in an enclosing tag. Did you want a JSX fragment <>...</>? (505:4)
```

Root cause (verified by reading the file): a previous edit removed the
`<ErrorBoundary>` opening tag and its import, but left the orphaned closing
tag at line 505. The outer `<div>` (line 364) is closed correctly at line
504; line 505 `</ErrorBoundary>` has no matching opener and `ErrorBoundary`
is not imported anywhere in `app.jsx`.

## Tasks

### 1. Remove the stray closing tag

- **files:** `apps/web/src/app.jsx`
- **action:** Delete line 505 (`    </ErrorBoundary>`) so the return
  statement ends with the balanced `</div>` at line 504.
- **verify:** `npm run build` in `apps/web` completes with no Babel/JSX
  parse errors.
- **done:** Build is green; no other JSX structure changed.

## Constraints

- Do not re-introduce an `<ErrorBoundary>` wrapper — that is a behavior
  change beyond the reported parse error; it can be a follow-up if wanted.
- No other files touched.
