## Problem

Vite build fails with:

```
[postcss] C:/Users/winst/Desktop/NASA/apps/web/src/index.css:285:1: Unclosed block
```

## Root cause

Merge commit `f462157` (Merge branch 'main' into narration-screen) interleaved
the chat branch's `bih-peek` comment + `@keyframes bih-peek` inside the PWA
branch's `html, body { touch-action: manipulation; }` rule at line 285 and
dropped its closing `}`. Verified by archaeology:

- `e21efed` (PWA implementation) had `html, body { touch-action: manipulation; }` closed correctly.
- `5b02229` added the peek keyframes cleanly (own comment, own block).
- `f462157` merge resolution spliced them together and lost the `}`.

## Fix

Restore the closing `}` after `touch-action: manipulation;` so the rule is:

```css
html,
body {
  touch-action: manipulation;
}
```

The `/* Peeking Silli tab */` comment stays attached to `@keyframes bih-peek`,
as in its original commit. No other content changes.

## Verification

- `npm run build` in `apps/web` completes with no PostCSS error.
- Brace balance sanity check on the file.
