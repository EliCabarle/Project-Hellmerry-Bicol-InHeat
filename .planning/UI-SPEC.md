## Page Layout + Section-by-Section Spec

**Structure: exactly 5 sections** in this DOM order (ui-ux-pro-max *Scroll-Triggered Storytelling*: Intro hook > problem > journey > solution > climax CTA; the footer closes):

```
screen === 'landing'
└─ <main id="main" class="landing-root">     ← own scroll container, bg #FFF7ED
   ├─ §1 Hero (Intro hook)      — h1 + wordmark + mascot + 2 CTAs
   ├─ §2 Problem
   ├─ §3 How it works (journey + solution)
   ├─ §4 Trust  ← closes with the single climax CTA band
   └─ §5 Footer
```

**Anti-clutter contract (binding):** exactly **1 H1** (hero hook only; every other section is H2) · **≤3 CTA buttons on the page** (hero ×2 + climax ×1) · **one idea per section** · section padding-y from the spacing scale (48/64/96) · no stock rocket/space imagery · **no emojis — SVG icons only** · every claim maps to a CONCEPT §8 CORE item (Claims table below) · decorative art is `aria-hidden`, never loads copy.

**Scroll container:** `html/body` are `overflow: hidden` globally (single-scrollbar contract in `index.css`). The landing root therefore owns scrolling: `id="main"`, `flex-1 min-h-0 overflow-y-auto bih-scroll`, `scroll-behavior: smooth`. **Every ScrollTrigger is created with `scroller: landingRoot`** — a trigger left on the document scroller will never fire. The screen does NOT render the spacer used by other screens; it does NOT render NavBar (below).

## Motion Spec (GSAP ScrollTrigger — locked decision)

**Dependency:** `gsap@3.15.1` (resolved `npm view gsap version`, 2026-11-14; Standard "no charge" license) added to `apps/web/package.json` by the **web-agent** — this spec does not edit it. **Install pre-approved by the lead 2026-11-14** (PLAN T8 legitimacy checkpoint closed — no mid-phase stop). Import: `import gsap from 'gsap'; import { ScrollTrigger } from 'gsap/ScrollTrigger'; gsap.registerPlugin(ScrollTrigger);` in the landing component only (never from `app.jsx` top-level — keep it out of the eager bundle path; `React.lazy` the landing screen if the main chunk grows).

**Universal rules:**
1. **Parallax on background/decorative layers only** — `aria-hidden`, `pointer-events: none`, absolutely positioned below content. **Never** on body copy, headings, badges, cards with text, or any interactive control.
2. **yPercent 5–15 per layer, `scrub: 0.6`**, `start: 'top bottom'`, `end: 'bottom top'`.
3. **≤3–4 layers per section** (below: hero 3, problem 2, how-it-works 2, trust 2, footer 0).
4. **All triggers pass `scroller: landingRoot`** (document scrolling is disabled globally).
5. **Entrances are additive:** base CSS/DOM is the final readable state; animate with `gsap.from(...)` so a failed/absent GSAP load leaves the page fully readable in DOM order.
6. **Tab hidden → pause:** `visibilitychange` → hidden: `gsap.ticker.sleep()` + `ScrollTrigger.getAll().forEach(t => t.disable())`; visible: `t.enable()` + `ScrollTrigger.refresh()` + `gsap.ticker.wake()`. Zero rAF work while hidden.
7. **Reduced motion → static final state:** wrap all creation in `gsap.matchMedia()`:
   - `(prefers-reduced-motion: no-preference)` → create entrances + scrub layers.
   - `(prefers-reduced-motion: reduce)` → **create nothing**; elements sit at CSS final state (the global `index.css` reduced-motion block also kills the 200 ms press). Static final state, not a 0-duration tween.

### Entrances

- **Hero (on mount, not scroll-triggered):** brand row → H1 → sub → CTAs, `from { opacity: 0, y: 16 }`, 500 ms `power2.out`, stagger 80 ms. Must complete ≤700 ms so first paint hooks immediately.
- **Sections §2–§4:** per-section container `from { opacity: 0, y: 24 }`, 500 ms, stagger 80 ms across children, `scrollTrigger: { trigger: section, start: 'top 80%', once: true, scroller }`.
- **Cards** get entrance only — never scrub (they are content).
- **Mobile ≤767: simplify** (landing.csv guidance): **no scrub parallax at all** — entrances only, `y: 12`, 400 ms. Reduces layer count to 0 on small screens.
- **Deliberate omission:** no scroll-progress indicator — 5 short sections, anti-clutter wins.

## A11y Contract (WCAG 2.2 AA)

1. **Contrast:** every text pair from the color table ≥4.5:1 — `#9A3412` on cream/white (6.9/7.3), white on `#2563EB` (5.17), `#0F172A` on `#F97316` (6.4). `#F97316` is banned as text. Verify the wordmark artwork ≥3:1 on cream (logo exemption applies, but ship it legible — fallback: white clay chip behind it).
2. **Focus:** visible `3px solid #0F172A` + `2px offset` on every interactive element; never removed. Keyboard order = DOM order: skip link → hero primary → hero Google → (scroll) climax CTA → footer links.
3. **Targets:** all CTAs ≥44×44 CSS px (52 px min-height spec'd); Google icon inside the button is not a separate target.
4. **Keyboard:** both hero CTAs and climax CTA are real `<button>`s (Enter/Space). No keyboard trap. AppMenu Home row inherits roving tabindex.
5. **Reading order:** complete and sensible with JS-driven animation disabled — base CSS is the final state, `gsap.from` only enhances; no CSS `order` swaps; decorative layers are `aria-hidden` and out of the tab order.
6. **Reduced motion:** `gsap.matchMedia` creates no tweens; `scroll-behavior: auto`; press transform disabled (extend the existing `index.css` block to `.clay-btn`). Content renders in final position.
7. **Semantics:** one `<h1>` (hero hook), `<h2>` per section, `<section>` wrappers, `<main id="main">` target of the existing skip link, images carry `width`/`height` (no CLS), wordmark `alt="Bicol In-Heat"`, mascot decorative `alt=""`.
8. **State announcements:** disabled Google CTA exposed via `aria-disabled`; OAuth failure `role="alert"`; no color-only encoding of meaning (significance claims are words, not hues).
9. **Language:** `lang="en"` already on `index.html`. UI English throughout.
