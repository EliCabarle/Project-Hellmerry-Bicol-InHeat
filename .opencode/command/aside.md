# aside — Answer a question without derailing

**Priorities keeping:**

1. Freeze your current task state exactly where it is.
2. Do not start new work, do not attempt the main task, do not wander.
3. Answer the side question directly.
4. When done, return to the frozen task and continue from exactly where you left off.

**Usage:**

`/aside <question>`
